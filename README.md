# Bynbo Montaje: descargas

Programa gratuito para montar en tu ordenador los vídeos de un podcast grabado con [Bynbo](https://bynbo.com). Sincroniza las cámaras, corta lo que sobra y genera el vídeo largo, los shorts y las portadas.

Descárgalo desde [bynbo.com/descargas](https://bynbo.com/descargas) o desde la [última versión](https://github.com/mesala/bynbo-descargas/releases/latest).

| Sistema | Fichero |
|---|---|
| Windows 10 u 11 (64 bits) | `Bynbo-Montaje-Windows.exe` |
| Mac con chip Apple (M1 o posterior) | `Bynbo-Montaje-Mac-Apple-Silicon.dmg` |
| Mac con Intel | `Bynbo-Montaje-Mac-Intel.dmg` |
| Debian, Ubuntu y derivados | `Bynbo-Montaje-Linux.deb` |
| Otros Linux | `Bynbo-Montaje-Linux.tar.gz` |

## Avisos al instalar

- **Windows:** va firmado por Glenlake Soft SL. Mientras la versión sea reciente aún puede salir «Windows protegió su PC»: pulsa «Más información» y «Ejecutar de todas formas».
- **Mac:** aún no lleva la firma de Apple. Arrastra el programa a Aplicaciones y ábrelo la primera vez con clic derecho → Abrir, o desde Ajustes → Privacidad y seguridad.
